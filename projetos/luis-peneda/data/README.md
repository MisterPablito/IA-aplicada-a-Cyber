# Dados

Esta pasta separa os dados versionados dos artefactos produzidos localmente.

## Conteudo versionado

- `raw/cybercrime_forensic_dataset.csv`: copia original do Cybercrime Forensic Dataset usada no projeto. Nao deve ser alterada pelos notebooks, scripts ou previsoes.

## Como utilizar

Os notebooks e modulos localizam este ficheiro a partir da raiz do repositorio. Nao e necessario descarregar ou mover o CSV depois de clonar o projeto.

Consultar [dados.md](../docs/dados.md) para a proveniencia, esquema, verificacao de integridade e limitacoes conhecidas. Os resultados e modelos gerados durante a execucao ficam em `../resultados/` e `../artefactos/`; estes ultimos nao sao versionados.
