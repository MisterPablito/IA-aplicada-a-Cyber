# Dataset

`cybersecurity_network_logs.csv` é o dataset original utilizado no projeto, obtido no [Kaggle — Cybersecurity Network Logs: Anomaly Detection](https://www.kaggle.com/datasets/aatmaca/cybersecurity-network-logs-anomaly-detection), de aatmaca.

O ficheiro contém 25 000 registos de ligações de rede e a variável alvo `Is_Malicious` (0 = normal, 1 = malicioso). Os scripts leem o dataset diretamente desta pasta.
